# Code of Conduct

## Our Commitment

Meanwhile is a professional framework project focused on advancing multi-agent collaboration technology. We are committed to providing a respectful, constructive environment for all contributors and users.

## Standards

### Expected Behavior

- Be professional and respectful in all interactions
- Provide and accept constructive feedback gracefully
- Focus on technical merit and project goals
- Respect differing viewpoints and experiences
- Show empathy toward other community members
- Keep discussions relevant and on-topic

### Unacceptable Behavior

- Harassment, intimidation, or discrimination of any kind
- Personal attacks, insults, or derogatory comments
- Trolling, inflammatory comments, or deliberate disruption
- Publishing others' private information without permission
- Spam or off-topic content
- Any conduct that would be inappropriate in a professional setting

## Scope

This Code of Conduct applies to:
- GitHub repository interactions (issues, PRs, discussions)
- Project communication channels
- Public representation of the project
- Any interaction where you represent the Meanwhile community

## Responsibilities

Project maintainers are responsible for:
- Clarifying standards of acceptable behavior
- Taking appropriate corrective action for unacceptable behavior
- Moderating comments, commits, issues, and other contributions
- Removing or banning contributors who violate this Code of Conduct

## Enforcement

Instances of unacceptable behavior may be reported by:
- Opening a private issue tagged with `code-of-conduct`
- Contacting the project maintainer directly

All complaints will be reviewed and investigated promptly and fairly. Project maintainers will maintain confidentiality regarding incident reporters.

### Consequences

Violations may result in:
1. **Warning**: A private or public warning about the behavior
2. **Temporary Ban**: Temporary suspension from project participation
3. **Permanent Ban**: Permanent removal from the project

The severity of consequences depends on the nature and context of the violation.

## Attribution

This Code of Conduct is focused on maintaining a professional, productive environment for framework development. It sets clear expectations for respectful technical collaboration.

## Questions

If you have questions about this Code of Conduct, please open an issue or contact the maintainers.
