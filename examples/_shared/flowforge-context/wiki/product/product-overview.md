# FlowForge Product Overview

**Last Updated:** January 2026  
**Owner:** Product Team

## What is FlowForge?

FlowForge is a B2B workflow automation platform that helps teams eliminate repetitive manual tasks by connecting their apps and automating multi-step processes. Think of it as "Zapier meets Monday.com" – we combine trigger-based automation with visual workflow builders and team collaboration features.

## Core Product Capabilities

### 1. Visual Workflow Builder
- Drag-and-drop canvas for building automation flows
- 200+ pre-built templates across categories
- Conditional logic, loops, and error handling
- Real-time preview and testing

### 2. App Integrations
- 150+ native integrations (Slack, Salesforce, HubSpot, Jira, etc.)
- Custom webhook support
- API connector for custom apps
- Database connectors (PostgreSQL, MySQL, MongoDB)

### 3. Team Collaboration
- Shared workflow library
- Role-based permissions (Admin, Editor, Viewer)
- Audit logs and version history
- Comments and annotations on workflows

### 4. Operations Dashboard
- Execution monitoring and logging
- Error alerts and retry mechanisms
- Usage analytics and optimization suggestions
- Scheduled workflow runs

## Key Metrics We Track

### North Star Metric
**Weekly Active Workflows (WAW):** Number of unique workflows that executed at least once in the past 7 days.

### Supporting Metrics
- **Activation Rate:** % of trial users who create and run their first workflow
- **Time to Value (TTV):** Days from signup to first successful workflow execution
- **Workflow Adoption:** Average workflows per paying customer
- **Net Revenue Retention:** Currently 112%
